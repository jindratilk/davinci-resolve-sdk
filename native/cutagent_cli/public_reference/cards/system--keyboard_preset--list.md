# `system keyboard-preset list`

Syntax: `cutagent system keyboard-preset list`

## Search terms

- system keyboard-preset list
- List available keyboard presets.
- system keyboard-preset list help
- system keyboard-preset list command

## What it does

List available keyboard presets.

## Do not use when

Do not infer that a keyboard preset is active merely because it appears in the catalog.

## Preflight and readback

Before running, connect to a supported DaVinci Resolve instance. Afterward, preserve the returned names exactly when displaying or comparing them. The command leaves projects, timelines, and keyboard settings unchanged.

## Public arguments and options

This command has no command-specific arguments or options.
