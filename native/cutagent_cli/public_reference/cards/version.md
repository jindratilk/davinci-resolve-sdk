# `version`

Syntax: `cutagent version`

## Search terms

- CutAgent CLI version
- DaVinci Resolve version
- version consistency check
- embedded bridge version
- CLI Resolve compatibility
- checkpoint command root

## What it does

Check the installed DaVinci Resolve version.

## Do not use when

Do not confuse `cutagent version` with global `cutagent --version`.
Do not use it to list or inspect project checkpoints; use `version list`, `version inspect`, or `version status`.

## Public arguments and options

This command has no command-specific arguments or options.

## Examples

- `cutagent version --help`
  Expected: Shows the public syntax, arguments, options, and documented defaults.
