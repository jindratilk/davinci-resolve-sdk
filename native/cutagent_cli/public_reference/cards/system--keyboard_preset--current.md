## What it does

Read the currently active keyboard preset.

## Do not use when

Use `system keyboard-preset list` for the available catalog. The active name does not describe the individual shortcut assignments.

## Preflight and readback

Before running, connect to a supported DaVinci Resolve instance. Afterward, preserve the returned name exactly. The command leaves projects, timelines, and keyboard settings unchanged.

This command has no command-specific arguments or options.
