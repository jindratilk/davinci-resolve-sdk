# Selected-source provenance

The user explicitly authorized extraction of the selected first-party SDK and local runtime into a standalone open-source distribution. This candidate uses the SDK's existing MIT license for that selected source. Original application/cloud licenses were not modified. The selected source inventory and installed dependency notices were reviewed for this source preview; any future bundled platform artifact requires its own inventory review.

The SDK source is copied in full from its existing public package; route and native implementation files are copied only as inventoried in the two extraction manifests. Original source hashes remain recorded. Selected native commercial admission is replaced by local process/argument ownership. The prepared runtime retains its original native handlers, exact targets, pre-state checks, verification and recovery, using private process-owned handles. Free mutations require the independent broker capability and expiring one-use exact command/native-call context. No commercial bypass token, fake subscription or Cloud signing key is supplied.

Node.js, Python, DaVinci Resolve, FFmpeg/FFprobe and LuaSocket binaries are not bundled. The selected Lua script retains the source Free spool implementation; standalone installation and broker lifecycle are composed, with live Free marker acceptance passed. DaVinciResolveScript is loaded from the user's installation.

The npm dependency lock and Python requirements lock record installed dependencies. Installed dependency license texts are preserved in THIRD_PARTY_NOTICES with package/version/hash inventory; the collection includes build dependencies. Two esbuild platform binary packages declare MIT but omit standalone license text in their installed package; those development binaries are not redistributed in the SDK tarball. Any future bundled runtime must review its actual dependency/platform inventory again. The candidate depends on express/zod and the existing SDK build tools; the selected native modules import rich and typer with their dependencies. Do not include the original Electron resource tree or unrelated commercial services to satisfy missing native owners.
